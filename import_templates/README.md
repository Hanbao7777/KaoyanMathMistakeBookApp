# 导入模板说明

这里放导入包模板和示例结构。

当前建议使用 `prompts/` 中的 GPT 提示词生成标准导入包：

- `考研高数错题整理专家_V2.md` -> `wrong_questions_import.zip`
- `考研数学教材识别专家.md` -> `knowledge_map_import.zip`

本目录不应放真实错题图片、真实教材内容或个人数据。

## 文件

- `wrong_questions_import_template.csv`：错题导入字段模板。
- `knowledge_map_import_schema_example.json`：知识地图 JSON 结构示例。
