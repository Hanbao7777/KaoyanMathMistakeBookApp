# Documentation Guide

Use the root documents for the current product view:

- [`../README.md`](../README.md) — product overview, setup, privacy, and user workflows.
- [`../ROADMAP.md`](../ROADMAP.md) — current priorities and delivery status.
- [`../KNOWN_ISSUES.md`](../KNOWN_ISSUES.md) — current limitations and regressions.
- [`design/`](design/) — active architecture and product-design notes.

Unresolved TickTick and knowledge-map plans/specifications remain in
[`superpowers/plans/`](superpowers/plans/) and [`superpowers/specs/`](superpowers/specs/).
Those directories are historical names; reading a plan does not authorize using a
Superpowers workflow.

The optional in-app AI/OCR Beta capability remains documented in the deferred
archive at [`archive/deferred/plans/`](archive/deferred/plans/). Its stabilization
and formalization are deferred for the personal-stable scope; the current personal
workflow imports mistakes directly through Codex/MCP.

[`archive/`](archive/) contains completed, superseded, and deliberately deferred
records. It preserves the original evidence and decision history; start with its
index when researching a past change.
