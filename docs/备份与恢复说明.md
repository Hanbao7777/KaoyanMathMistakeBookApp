# 备份与恢复说明

## 手动备份

设置页提供“一键备份数据库”按钮。备份文件保存到：

```text
D:\KaoyanMathMistakeBook\backups
```

手动备份不会被自动清理。

## 自动备份

App 启动时会检查当天是否已有自动备份。如果没有，会自动创建一次。

自动备份文件名类似：

```text
mistakes_auto_2026-05-03_10-30-00.db
```

自动备份最多保留最近 30 个。

## 恢复备份

恢复备份会覆盖当前数据库。为降低风险，恢复前会自动创建：

```text
mistakes_before_restore_YYYY-MM-DD_HH-mm-ss.db
```

恢复完成后建议重启 App，确保所有页面重新加载数据库。
