# 考点汇总替换知识地图 — 设计文档

## 目标

将现有知识地图模块的数据源从"AI 生成的教材知识树"替换为"考研数学考点汇总"，实现：
1. 内置考点汇总数据，App 首次启动自动导入
2. 已有错题自动重新匹配到新考点
3. 未来 OCR/手动导入的错题也能匹配到新考点

## 决策记录

| 决策 | 选择 | 理由 |
|------|------|------|
| 数据策略 | 完全替换 | 清除旧数据，用考点汇总重建 |
| 元数据来源 | AI 预生成 | 一次性生成，零运行时 API 调用 |
| 触发方式 | 首次启动自动导入 | 检测 knowledge_points 表为空时触发 |
| 重匹配时机 | 导入后自动执行 | 无需用户手动操作 |
| 层级结构 | 按原文 3 层映射 | 保留原始结构 |

## 数据结构映射

### 高等数学

| 层级 | 示例 | node_id 示例 |
|------|------|-------------|
| Level 1 (subject) | 高等数学 | `gaoshu` |
| Level 2 (chapter) | 1：函数、极限、连续 | `gs_ch1_limit_continuity` |
| Level 3 (knowledge point) | 数列敛散性的判定 | `gs_ch1_sequence_convergence` |

### 线性代数

| 层级 | 示例 | node_id 示例 |
|------|------|-------------|
| Level 1 (subject) | 线性代数 | `xiandai` |
| Level 2 (chapter) | 一：行列式 | `xd_determinant` |
| Level 3 (sub-chapter) | 1：矩阵 | `xd_determinant_matrix` |
| Level 4 (knowledge point) | 矩阵的运算和变换 | `xd_determinant_matrix_operations` |

### node_id 命名规则

- 格式：`{subject_prefix}_{chapter_info}_{pinyin_slug}`
- 高等数学前缀：`gs_`
- 线性代数前缀：`xd_`
- 全小写，下划线分隔
- 稳定不变，作为外键关联目标

### AI 丰富字段

每个考点生成以下元数据：
- `summary`：核心描述（50-100 字）
- `core_formulas`：相关 LaTeX 公式数组
- `common_question_types`：常见题型数组
- `common_error_reasons`：常见错误原因数组
- `tags`：关键词标签数组（用于匹配）

### textbooks.json

```json
{
  "title": "考研数学考点汇总",
  "subject": "通用",
  "edition": "2026",
  "file_name": null,
  "note": "基于考点汇总自动生成"
}
```

knowledge_points 的 `textbook_id` 设为 null（不绑定特定教材）。

## 实现架构

### 流程

```
考点汇总.txt → [AI处理] → knowledge_map_seed.zip
                                    ↓
                        打包进 App resources/
                                    ↓
                    App 首次启动检测 knowledge_points 表为空
                                    ↓
                        自动调用 seedImportKnowledgeMap()
                                    ↓
                        导入知识点 + 自动重匹配已有错题
```

1. App 的章节分类下拉框（CATEGORIES）
2. AI 结构化导入的 prompt（deepseekService.ts）
3. 错题整理专家 GPT 提示词（prompts/考研高数错题整理专家_V2.md）

## 验收标准

1. App 首次启动（或 knowledge_points 表为空时）自动导入考点汇总
2. 导入后知识地图页面正确展示完整考点树
3. 已有错题自动关联到新考点（通过重匹配）
4. 已有错题的旧 category 值自动迁移到新值
5. 新导入的错题（OCR/手动）能匹配到考点
6. 前端章节分类下拉框显示新分类列表
7. AI 结构化导入使用新 category 和新考点标题
8. 前端展示、复习统计、考点详情页功能正常

## 风险与缓解

| 风险 | 缓解措施 |
|------|---------|
| AI 生成的 node_id 不稳定 | 预生成时固定 node_id，写入 seed zip |
| 已有关联数据丢失 | 完全替换策略下预期丢失，通过重匹配恢复 |
| 考点汇总更新需要发版 | 可后续支持"更新考点"功能 |
| seed zip 文件损坏 | 启动时校验，失败则跳过并记录日志 |
| "线性代数"旧错题无法自动归入子类 | 迁移到"其他"，提示用户手动重分 |
| 无穷级数/概率论不在新考点汇总中 | 暂时保留分类，后续考点汇覆盖后再处理 |
