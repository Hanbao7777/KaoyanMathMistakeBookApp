# 常见问题

## 为什么 App 不直接识别图片？

为了保持本地稳定和可维护，App 不内置 OCR 或 AI 识别。图片识别、分类和标签整理由用户在外部 GPT 工具中完成。

## 为什么不内置 OCR？

OCR 的准确率、成本和隐私边界较复杂。当前版本专注于本地保存、复习计划和知识地图管理。

## 为什么 PDF 不能自动跳转指定页？

外部 PDF 阅读器不一定支持 `file:///xxx.pdf#page=55`。App 会打开 PDF、显示目标页码，并提供复制 PDF 页码功能。

## 教材 PDF 应该放哪里？

默认放在：

```text
D:\KaoyanMathMistakeBook\textbooks
```

也可以在知识地图页面手动绑定教材 PDF。

## 为什么知识点没有关联错题？

可能是错题包中没有 `knowledge_points` 字段，或字段没有匹配到知识点 `node_id` / 标题。可以在知识地图页面点击“重新匹配已有错题知识点”。

## 如何备份数据库？

进入设置页，点击“一键备份数据库”。App 也会每天自动备份一次。

## PDF 导出为什么有排版问题？

PDF 导出目前为 Beta，复杂公式和长图分页仍可能存在不完美情况。

## 可以导入其他数学科目吗？

可以尝试。只要导入包字段符合格式，App 不限制具体科目。

## 数据会上传吗？

不会。App 默认把数据保存在本机 `D:\KaoyanMathMistakeBook`。
