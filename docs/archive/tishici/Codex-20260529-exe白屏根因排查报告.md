# Codex 排查报告：双击 exe 后白屏

日期：2026-05-29  
排查人：Codex  
问题范围：Electron 打包版启动后渲染进程白屏

## 结论

白屏根因在 `src/renderer/App.tsx`：一个 `useEffect` 被错误地写进了另一个 `useEffect` 的回调内部。

这会违反 React Hooks 规则。TypeScript 能通过，但 React 运行时会触发 `Invalid hook call`，导致 renderer 崩溃，最终用户看到空白页。

## 根因位置

文件：

```text
src/renderer/App.tsx
```

出错前代码形态：

```tsx
useEffect(() => {
  window.api.triggerReviewTaskGeneration().catch((e) => { console.error('triggerReviewTaskGeneration', e); });

useEffect(() => {
  try {
    if (localStorage.getItem('kaoyan-dark-mode') === 'true') {
      document.documentElement.classList.add('dark');
    }
  } catch {}
}, []);
}, []);
```

问题点：

- 第二个 `useEffect` 在第一个 `useEffect` 的 callback 内部调用。
- Hooks 只能在 React function component 的顶层调用，不能在 effect callback、条件分支、循环、普通函数里调用。
- 这个错误不会被当前 `tsc --noEmit` 检出，因为语法和类型都是合法的。
- 打包后的 bundle 里也确认包含了错误逻辑。

## 修复内容

已把两个 effect 拆成并列顶层 Hook：

```tsx
useEffect(() => {
  window.api.triggerReviewTaskGeneration().catch((e) => { console.error('triggerReviewTaskGeneration', e); });
}, []);

useEffect(() => {
  try {
    if (localStorage.getItem('kaoyan-dark-mode') === 'true') {
      document.documentElement.classList.add('dark');
    }

}, []);
```

## 为什么 Claude Code 之前可能没发现

原因是当前验证链路主要依赖：

```bash
npx tsc --noEmit
npx tsc -p tsconfig.main.json --noEmit
npm run build
npm run pack:win
```

这些步骤不能保证 React Hooks 运行时规则被检查出来。`useEffect` 嵌套在 effect callback 里对 TypeScript 来说是合法函数调用，只有 React 执行到这里才会报错。

建议补充：

```bash
npm install -D eslint eslint-plugin-react-hooks
```

并启用：

```json
{
  "plugins": ["react-hooks"],
  "rules": {
    "react-hooks/rules-of-hooks": "error",
    "react-hooks/exhaustive-deps": "warn"
  }
}
```

这样后续可以在提交前拦住类似问题。

## 后续建议

1. 每次改 `App.tsx` 这类顶层组件后，除了 typecheck/build，还要实际启动 Electron 打包版。
2. 用 remote debugging 抓 renderer console，不要只看主进程是否启动。
3. 给项目补 ESLint React Hooks 规则，避免再次出现“构建通过但运行白屏”的问题。
4. 如果继续改 Widget，注意主窗口和 Widget 窗口的入口条件必须明确区分，避免主窗口误进 `#/widget` 分支。
