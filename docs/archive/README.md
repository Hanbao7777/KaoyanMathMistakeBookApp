# Documentation Archive

This archive preserves records instead of deleting them. A document moves here
only when the repository contains explicit completion evidence or a later current
record supersedes its plan. The historical text is retained; its placement is not
a claim that every future product concern is resolved.

## Completed

- [`completed/tasks/`](completed/tasks/) — accepted task plans, execution records,
  evidence, audits, and closure records. This includes the closed Agent Control
  Plane phases, the completed personal-stability cycle, and the completed GitHub
  Actions Node24 runtime upgrade.
- [`completed/plans/`](completed/plans/) — completed interaction, regression-test,
  and CI implementation plans.
- [`completed/specs/`](completed/specs/) — completed regression-test design records.

## Superseded

- [`superseded/tasks/`](superseded/tasks/) — the earlier mistake-book P0 brief
  replaced by the accepted personal-stability plan/evidence, plus a C14
  consent/runtime proposal made obsolete by the later accepted Phase C completion
  record.
- [`superseded/plans/`](superseded/plans/) and [`superseded/specs/`](superseded/specs/)
  — TickTick P0 closure records superseded by the current TickTick known-issues
  entry point and subsequent closure records.

## Deferred

- [`deferred/plans/`](deferred/plans/) — optional Beta capabilities retained as
  product documentation, but deliberately outside the personal-stable scope. The
  AI/OCR plan is deferred because the current personal workflow imports mistakes
  directly through Codex/MCP; this does not remove or mark the capability complete.

## Kept outside the archive

Unresolved or still-relevant material remains in its original location: the root
status documents, user guides, architecture/design notes, and the unresolved
TickTick and knowledge-map plans/specifications. They were not archived merely
because of their dates. `docs/tasks/` currently has no dated active task record.
