# 导入知识地图包说明

知识地图包文件名建议为：

```text
knowledge_map_import.zip
```

结构：

```text
knowledge_map_import.zip
├── textbooks.json
└── knowledge_points.json
```

## textbooks.json

用于保存教材信息，例如：

```json
{
  "title": "高等数学示例教材",
  "subject": "高等数学",
  "edition": "2026",
  "file_name": "example.pdf",
  "note": "示例教材信息"
}
```

## knowledge_points.json

用于保存知识点树。关键字段：

- `node_id`：知识点唯一 ID。
- `parent_node_id`：父节点 ID。
- `title`：知识点名称。
- `category`：所属章节。
- `level`：层级。
- `book_page`：书本印刷页码。
- `pdf_page`：PDF 实际页码。
- `summary`：知识点说明。
- `common_question_types`：常见题型。
- `common_error_reasons`：常见错因。
- `tags`：标签。

## 教材 PDF

默认知识地图包可以不包含 PDF。用户需要将教材 PDF 放入：

```text
D:\KaoyanMathMistakeBook\textbooks
```

如果 `textbooks.json` 中的 `file_name` 与本地 PDF 文件名完全一致，App 可以自动查找。也可以在知识地图页面手动绑定 PDF。

外部 PDF 阅读器不一定支持自动跳页，因此 App 会显示“PDF 第几页 / 书本第几页”，并提供复制 PDF 页码。
