# 使用说明

考研高数错题本 App 是一个本地优先的桌面错题管理与复习工具。

## 基本流程

1. 使用 GPT 提示词生成知识地图包和错题包。
2. 在“导入数据”页导入 `knowledge_map_import.zip`。
3. 将教材 PDF 放入 `D:\KaoyanMathMistakeBook\textbooks`，或在知识地图中绑定 PDF。
4. 在“导入数据”页导入 `wrong_questions_import.zip`。
5. 在知识地图中点击“重新匹配已有错题知识点”。
6. 从 Dashboard 或复习中心开始复习。

## 主要页面

- 首页：学习总览、今日建议、薄弱知识点。
- 错题库：搜索、筛选、导出 PDF 错题集。
- 错题详情：题目、错题原图、解析、答案、复习状态。
- 复习中心：今日复习、薄弱复习、随机复习、按知识点复习。
- 知识地图：教材知识点、页码、相关错题和图谱视图。
- 统计：学习诊断中心。
- 设置：数据目录、备份、恢复、JSON 导入导出。

## 注意

App 不内置 OCR 或 AI，不会自动识别图片内容。识别和整理工作由用户在外部 GPT 工具中完成。
